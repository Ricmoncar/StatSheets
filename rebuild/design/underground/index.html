TYPE AND BUILD NOTES

What a developer needs to rebuild every page from this system.

Three fonts, three jobs. Jersey 10 is tall and condensed like painted signboards: names, plaques, gold, big numbers (sizes 30, 40, 60). Silkscreen is small pixel caps for every label, button and tab, used only at 16px so each font pixel is exactly 2 CSS px. VT323 is monospaced, so stat columns line up, and it reads like the game's dialogue: body text, descriptions, every dense number (20 to 32px). Press Start 2P is retired: it is too wide for dense sheets.

PIXEL GRID

  • One art pixel is --px: 3 CSS px on desktop, 2 below 720px. Nothing is ever drawn at a fraction of it.
  • All sizes are written as calc(N * var(--px)): borders, gaps, sprites, shadows, focus rings.
  • Bitmaps are drawn at 1:1 into canvases, exported as data URLs and scaled by an integer with image-rendering: pixelated.
  • Icons are inline SVG on a 7 by 7 grid with shape-rendering="crispEdges" so they take currentColor.
  • No blur, no soft shadow, no smooth gradient. Shadows are a solid 2 pixel drop in void. Fades are dithers or banded ramps.
  • Text is allowed one finer step (16px Silkscreen = 2 CSS px per font pixel) and never smaller.

FRAMES . 9-SLICE

Every frame is one small canvas: corners of D by D, edge tiles of length L that repeat, an empty centre. CSS draws it with border-image-source, border-image-slice: D, border-width: D * --px and border-image-repeat: repeat, so a panel of any size keeps whole pixels and the bricks never stretch. The fill is a flat background-color clipped to the padding box.

Never an easing curve on pixel art. Position only moves in whole art pixels. Nothing loops faster than 12 fps, so it reads as sprite animation, not as a web transition.

ACCENT RECOLOUR

The character's accent goes through OKLCH and comes out as two ramps, written to :root as tokens:

  • --ac0..4: shadow, dark, base, light, highlight. Shadows shift hue toward violet, highlights toward yellow, lightness is fixed per step so any custom colour gives a usable ramp.
  • --sn0..3: the stone ramp. Accent hue at very low chroma, so a violet accent gives Ruins purple and a lime one gives mossy slate.
  • --on-ac: void or white, whichever reads on the base.

Sprites are palette-index grids. When the accent changes, every sprite that uses an accent index is redrawn from the new ramp and its data URL is swapped. Wood, metal, snow, fire and the SOUL never use accent indices, so materials stay recognisable.

PERFORMANCE MODE

  • Background canvases draw one frame and stop their timers.
  • All sprite and texture animations pause on their current frame.
  • Particles (embers, glints, sweeps) are removed.
  • Typewriter text appears at once. Card flips jump to the result.
  • Frames and textures stay: they are static images and cost nothing.
  • prefers-reduced-motion: reduce turns this on automatically.
